# Day09 多线程采集与写盘

## 1. 今日目标

1. 理解采集线程与存盘线程分离的意义。
2. 避免“采集线程被磁盘写入拖慢”。
3. 学会基本队列背压观测。

## 2. 设计建议

1. 线程A：只做 `DQBUF -> 复制/引用 -> QBUF`。
2. 线程B：负责写文件或后处理。
3. 中间用有界队列。

## 3. 关键指标

1. 队列深度（当前/峰值）。
2. 采集端等待时间。
3. 写盘端平均耗时。
4. 丢帧数（若队列满）。

## 4. 代码任务

1. 新建 `v4l2_capture_multithread.cpp`（可从单帧版拷贝改造）。
2. 先实现最简版本：固定抓 200 帧，仅保存每 10 帧。

## 5. 验收标准

1. 连续采集稳定，无明显阻塞。
2. 能输出队列峰值和丢帧统计。
