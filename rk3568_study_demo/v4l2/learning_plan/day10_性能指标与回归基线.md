# Day10 性能指标与回归基线

## 1. 今日目标

1. 建立可重复对比的指标体系。
2. 为后续优化准备“基线”。
3. 把“看起来流畅”转成“可量化”。

## 2. 指标建议

1. `fps_avg`
2. `dqbuf_wait_avg_us`
3. `dqbuf_wait_p99_us`
4. `select_timeout_count`
5. `drop_count`
6. `cpu_usage`（可选）

## 3. 动手任务

1. 同一参数跑 3 轮，记录均值和波动。
2. 改一个变量（如分辨率），再跑 3 轮。
3. 对比差异，写出结论。

## 4. 验收标准

1. 你有一份基线表（至少两组参数）。
2. 结论有数字，不是口头判断。
