# Week3 内存专项：SoC 音视频岗位深挖清单

> 目标：把“会写代码”升级为“能定位内存瓶颈、能给出可落地方案”。

## 1. 你这个岗位必须掌握的内存知识（按优先级）

1. P0：页错误与首帧抖动
   - 关键词：`minor fault`、`major fault`、按需分配、预热
   - 场景：首次打开预览/录制时卡一下
   - 你要会：如何把触页前移到初始化阶段

2. P0：固定缓冲池与生命周期闭环
   - 关键词：预分配、复用、归还、泄漏检查
   - 场景：高帧率下频繁 malloc/free 导致抖动
   - 你要会：用池化稳定延迟并做“无泄漏”验证

3. P0：背压与队列深度
   - 关键词：吞吐、排队时延、峰值深度
   - 场景：不卡但延迟越来越高
   - 你要会：判断“应该加队列”还是“应该减负载/丢帧”

4. P1：缓存局部性与伪共享
   - 关键词：cache line、false sharing、顺序访问
   - 场景：多线程统计/调度数据更新效率低
   - 你要会：结构体布局与线程写热点隔离

5. P1：对齐与零拷贝
   - 关键词：64B 对齐、DMA 友好、memcpy 成本
   - 场景：CPU 带宽被拷贝吃满
   - 你要会：识别并减少不必要拷贝路径

6. P2：内存序与同步语义（和锁联动）
   - 关键词：atomic、release/acquire、可见性
   - 场景：控制线程更新参数后数据线程读取异常
   - 你要会：分清原子性、可见性、一致性边界
